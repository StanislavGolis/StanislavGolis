## Проекты

### Dredger — медиа-архив

Сервис сбора, обработки и публикации медиаконтента: адаптеры источников → S3 → деривативы (превью, видео) → каталог с поиском и ролями.

`Python` `FastAPI` `SQLAlchemy 2 async` `Alembic` `boto3` `Redis` `Next.js` `nginx` `Docker`

~41 700 строк кода · **183 коммита** · **42 миграции** · развёрнут на реальном сервере · [репозиторий](https://github.com/StanislavGolis/parser)

Адаптеры источников с общим интерфейсом, подписанные ссылки с TTL, кэш деривативов на диске nginx, идемпотентные платежи

### Карамель — дейтинг по событиям (Action-first dating)

Не лента анкет, а карточка конкретной встречи: «иду в кино в пятницу, ищу компанию». Чат открывается только после того, как компания собралась.

`Python` `FastAPI` `SQLAlchemy 2 async` `PostgreSQL 16` `Redis 7` `Next.js 16` `React 19` `TypeScript` `Docker`

~42 400 строк Python · ~12 800 строк TypeScript · **380 тестов** · 40 миграций · [репозиторий](https://github.com/StanislavGolis/karamel)

AES-256-GCM для переписки, точные координаты не хранятся, инварианты вынесены в БД, производные состояния в Python и SQL `CASE` с CHECK-стражем

### СтройДок — контроль комплектности документации для ПТО

Система для строительного отдела ПТО: мастер-список по рабочей документации, матрица закрытия позиций, автоматическая генерация актов (АВК, АОСР, ВСО, ВР).

`Python` `FastAPI` `SQLAlchemy 2 async` `PostgreSQL` `Next.js` `TypeScript` `Tailwind` `Docker`

~9 700 строк кода · 31 коммит · **44 эндпоинта** · 8 миграций · [репозиторий](https://github.com/StanislavGolis/StroyDoc)

**Статус: MVP в разработке.** Бэкенд реализован, экран конструктора актов — в работе. Домен ПТО знаю изнутри по работе инженером ПНР

### ГеоПульс — тепловые карты плотности бизнеса

Веб-сервис для предпринимателей малого бизнеса: где на карте города уже есть конкуренты, а где пусто. H3-сетка, данные OpenStreetMap.

`Python` `FastAPI` `H3` `React` `TypeScript` `PostgreSQL` `Docker`

## Как я работаю

- **Тесты как проверяемое утверждение.** Не «покрытие ради галочки»: тесты ловят именно те дефекты, которые уже случались. После инцидента с тестом, съевшим 14 ГБ RAM, введён `pytest-timeout` во всех пакетах.
- **Решения записаны.** ADR, реестр технического долга с адресом каждого долга, миграции как отдельный шаг, а не скрытое изменение схемы при рестарте.
- **Границы названы честно.** Что не входит в MVP и почему — фиксируется до написания кода.
- **AI-агенты как исполнительная мощность.** Часть кода написана агентами под моим управлением: я задаю истории, проверяю результат и отвечаю за то, что уходит в коммит. Это не скрывается — это часть того, как я работаю.
